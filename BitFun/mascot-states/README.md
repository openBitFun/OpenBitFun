# 毕方形象 · 多状态设计与配色

OpenBitFun 吉祥物“毕方”的设计稿与生成代码。形象以等距视角的圆角方块为底座：顶面一根短天线和天线球，右侧面一对竖椭圆眼睛。天线球的颜色表示 Agent 当前的工作状态，共 14 个状态。

## 快速查看

直接用浏览器打开 `bitfun-mascot.html`。这是合成后的完整单文件，无需联网或本地服务，依次包含三个章节：

| 章节 | 内容 | 独立页面 |
|---|---|---|
| 01 自己搭配 | 选择身体和天线球颜色、质感、眼睛、嘴型（无 / 鸟嘴 / 随状态 / 微笑 / 猫猫嘴 / 小圆嘴）、腮红（无 / 珊瑚 / 粉 / 蜜桃 / 玫瑰）；实时预览 3D、平面、6 个状态、小尺寸图标；导出 SVG 和配色 JSON | `dist/pages/customize.html` |
| 02 形象与状态 | 《山海经》典故、毛绒动态版（可撸毛、抖一抖、调风力、侧面 / 正面切换）、形象构成、设计理念、14 个状态、小尺寸规则、产品内示意、使用规则 | `dist/pages/states.html` |
| 03 配色方案 | 统一色板：18 种身体色（含 8 种设计系统身份色和毕方特别版）+ 7 种天线球色，每种身体色的默认搭配 | `dist/pages/palettes.html` |

## 构建

需要 Node.js 18 及以上，无第三方依赖。

```bash
npm run build        # 等同于 node src/build.js
```

构建会更新 `bitfun-mascot.html`，并清空、重新生成 `dist/`（三个独立页面、2016 个 SVG、色卡）。`dist/` 不随仓库提交，需要 SVG 时在本地构建一次即可。

## 设计要点

- **身体**：等距圆角方块，所有状态形体一致，只允许压扁、晃动这类弹性形变。3D 有光滑、金属、毛绒三种质感；平面视图只有纯色一种。
- **天线球 = 状态灯**：思考紫、执行蓝、需要你琥珀、完成绿、异常红、离线灰。球内不放任何图标，只靠颜色和动效区分状态。待命色必须避开这几个色相。
- **眼睛**：按身体的感知亮度自动选择，OKLab L < 0.70 用白眼，否则用黑眼；内置的身体颜色在浅色、深色主题下眼睛对比度都不低于 3:1；用户自定义颜色时由“自己搭配”的检查项提示。眼型包括常态、放大、专注、眯眼、亮眼（完成：眼睛略睁大，旁边闪一颗小星芒）、眼缝（离线）、`> <`（异常）。
- **浅色身体**：相对亮度 > 0.72 时自动加一圈同色系细轮廓，避免在浅底上消失。
- **毕方特别版**：按《山海经》“其状如鹤，一足，赤文青质而白喙”取色——青色身体；“赤文”收成一对珊瑚色腮红（不用正红，避免像血），形状清楚、跟表情结合，所有质感和平面版一致；毛绒版两颊的毛更短、毛尖微微泛暖。眼下一只小白喙；天线即“一足”。
- **统一色板**：全文件只用 `src/core/bitfun-states.js` 里的 `BOARD`（身体色 + 天线球色），三个章节同源。
- **毛绒**：全部由代码生成（SVG 路径，不是贴图）。参考华为鸿蒙“憨憨”的长毛：分层抖动采样让各面分布均匀；绒毛成簇、顺着流向场梳理，每根毛分根 / 中 / 尖三段，越往尖越细越亮，受光压得很弱（各面只差一点明暗，看到的是毛本身的颜色），全部不透明；底下先铺一层短而密的底绒（不摆动），整只都被毛覆盖、不露底。眼睛做成有体积的小珠子（柔和明暗 + 一点高光和投影），周围轻轻压暗成眼窝；喙上沿压几根短绒；天线不放金属托盘、直接插进毛里；天线球用哑光球（柔和明暗、无镜面高光）。脸部（两眼周围）的毛更短、从脸中心向外梳，表情更清楚。毛分成 4 组各自按不同节奏轻摆，鼠标划过时依次抖动。
- **毛绒动态版**：在“形象与状态”章节。4 组绒毛各是一个阻尼弹簧，受风、鼠标拨动和身体甩动的惯性驱动；为保证 60fps，运行时把 SVG 拆成多层（底绒+身体 / 每组每段绒毛 / 眼睛和天线），每层只做 CSS 旋转交给 GPU 合成。
- **尺寸分级**：≥ 64px 显示完整道具；32–63px 去掉道具；< 32px 自动切换为平面图标版。

## 与 OpenBitFun 设计系统的关系

- 页面样式（背景、文字、描边、圆角、间距、字号）全部使用 `--openbitfun-*` 变量，数值来自 `src/tokens/openbitfun-tokens.json`。
- token 来源：仓库 `Cinnnnnnndy/OpenBitFun`，分支 `feat/mobile-design-lab-fusion`，路径 `design-system/packages/theme-openbitfun/src/*.tokens.json` 与 `design-system/packages/design-tokens/src/system.tokens.json`。设计系统更新后，请同步这个文件再重新构建。
- 身体颜色中只有设计系统身份色（`color.identity.project.*`）是 token；状态球使用 `color.status.*.emphasis`。

### 待确认

- “思考”状态没有对应的状态 token，暂用 `color.accent.secondary`。
- 中性色、高饱和色、AI 光晕色（主推方案里标“非 token”的颜色）尚未进入设计系统；进入产品前需要补充 token 或替换。
- 页面是静态设计稿，交互控件使用原生表单元素，没有使用 `@openbitfun/ui` 组件；如需放入 Design Lab，需要用库组件重写。
- 形象内部的明暗、高光、毛绒纹理属于插画绘制，不对应 token。
